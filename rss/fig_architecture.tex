\caption{GaitNet architecture. (a)~Each tick, GaitNet samples safe
  footholds around each hip. (b)~The planner encodes the state and the
  last second of motion into a context $\mathbf z$, embeds each candidate
  (and the learned no-step option), lets the choices attend to each other
  in the candidate mixer, and picks one step: a leg, a landing point, and
  a swing time. (c)~A controller-specific inverse footstep model turns the
  landing point into the command that lands there.}
\label{fig:architecture}
